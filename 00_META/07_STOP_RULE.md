# Strict Task Execution Format (Kilo Code Standard)

Mọi task thực thi phức tạp yêu cầu cấu trúc chuẩn:

1. Context: Ngữ cảnh bài toán
2. Goal: Mục tiêu chi tiết
3. Input: Bảng dữ liệu / Mã nguồn / Tài liệu đầu vào
4. Constraints: Các ràng buộc về kỹ thuật hay quy trình
5. Process: Các bước triển khai tuần tự
6. Output: Định dạng kết quả đầu ra
7. Verify: Phương pháp kiểm tra tính đúng đắn
8. STOP: Dừng lại xin xác nhận từ người dùng trước khi thực hiện bước tiếp theo (nếu có nghi vấn hoặc thay đổi lớn)
